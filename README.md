# Global-Country-Analysis-Insights-Dashboard
Global Country Analysis &amp; Insights Dashboard is an interactive Power BI dashboard that analyzes global country data based on population, GDP, area, population density, regions, and economic categories. It provides clear visual insights and country comparisons to understand global demographic, economic, and geographical patterns.

## Project Objective

The objective of this project is to analyze global country data using Power BI. The dashboard provides insights into population, GDP, area, population density, geography, regions, and economic performance. It helps users compare countries and identify demographic, economic, and geographical patterns through interactive visualizations.

## Dataset Used

The dataset contains global country-level information, including country name, country code, capital, region, subregion, population, area, population density, GDP, GDP per capita, languages, currency, latitude, longitude, border count, timezone count, island status, population rank, density rank, GDP rank, density category, and economic category.


## Questions (KPIs)

* What is the Total Population?
* What is the Total GDP?
* What is the Total Area of Countries?
* What is the Average Population Density?
* How many Countries are included?
* Which Country has the Highest Population?
* Which Country has the Highest GDP?
* Which Region has the Highest Population?
* Which Country has the Highest GDP per Capita?
* Which Economic Category has the Highest GDP?

## Process

* ### Data Collection

  Used a global country dataset containing demographic, economic, geographical, and country-level information.

* ### Data Preparation

  Cleaned and organized the country data by handling required fields and preparing the dataset for Power BI analysis.

* ### Data Transformation

  Created and prepared calculated fields such as Population in Millions, Population Density, GDP per Capita, Population Rank, GDP Rank, Density Rank, Density Category, and Economic Category.

* ### Data Analysis

  Analyzed population, GDP, area, population density, regions, subregions, economic categories, and geographical characteristics of countries.

* ### KPI Calculation

  Created key performance indicators to measure population, GDP, country count, area, density, and economic performance.

* ### Visual Analysis

  Created charts and visualizations to compare countries, regions, population, GDP, area, density, and economic performance.

* ### Dashboard Development

  Developed an interactive Power BI dashboard using KPI cards, charts, tables, slicers, and visualizations to present country-level insights in an easy-to-understand format.

* ### Business Insights

  Used the dashboard to understand global demographic patterns, economic performance, regional differences, population density, and geographical characteristics.

## Business Insights

* ### Population Analysis:

  The dashboard compares countries based on their total population and population rankings, helping identify highly and sparsely populated countries.

* ### Regional Performance:

  Countries can be compared across different regions and subregions to understand variations in population and economic performance.

* ### Economic Analysis:

  GDP and GDP per capita are analyzed to identify countries with stronger economic performance.

* ### Population Density:

  Population density helps identify countries with high and low population concentration in relation to their geographical area.

* ### Geographical Analysis:

  Country area, latitude, longitude, border count, timezone count, and island status provide insights into geographical characteristics.

* ### GDP Trend:

  GDP by year is analyzed to understand changes in economic performance over time.

* ### Economic Category:

  Countries are grouped into economic categories to compare their overall economic position.

* ### Country Comparison:

  The dashboard allows users to filter and compare countries based on region, subregion, economic category, population, GDP, and density.

## Final Conclusion

The Global Country Analysis & Insights Dashboard provides a comprehensive view of countries based on demographic, economic, and geographical factors. Power BI helps transform country-level data into meaningful visual insights, making it easier to compare countries, identify regional patterns, understand population distribution, and analyze economic performance.
